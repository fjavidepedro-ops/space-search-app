📡 DATOS ESPECÍFICOS DISPONIBLES
═══════════════════════════════════════════════════════════════════════════

ISS (Estación Espacial Internacional):
  ✓ Posición actual GPS
  ✓ Altitud: 408 km
  ✓ Velocidad: 28,000 km/h
  ✓ Período orbital: 90 minutos
  ✓ Tripulación: ~7 astronautas

Hubble Space Telescope:
  ✓ Altitud: 559 km
  ✓ Operativo desde: 1990 (34 años)
  ✓ Descubrimientos: Miles de galaxias
  ✓ Imágenes de alta resolución

Marte:
  ✓ Rovers activos: Perseverance, Zhurong
  ✓ Descubrimientos científicos
  ✓ Imágenes del terreno
  ✓ Objetivos: Colonización humana (2040s)

📞 PROBLEMAS?
═══════════════════════════════════════════════════════════════════════════

"No funciona la app":
  → Verifica Python: python --version
  → Verifica carpeta correcta
  → Reinicia cmd y intenta de nuevo

"No veo resultados":
  → Espera 3-5 segundos (carga datos)
  → Intenta otra búsqueda
  → Usa palabras clave: "NASA", "ISS", "satélite"

"Error de red":
  → Verifica conexión a internet
  → Comprueba que Python sigue corriendo
  → Cierra navegador y abre de nuevo
