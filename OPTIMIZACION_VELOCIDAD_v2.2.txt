📝 CAMBIOS TÉCNICOS DETALLADOS
════════════════════════════════════════════════════════════════════════════

1. FUNCIÓN withTimeout() - NUEVA
   ─────────────────────────────
   
   Qué hace:
   • Limita el tiempo de espera para cada promesa
   • Si tarda más → cancela automáticamente
   • Si falla → devuelve resultados vacíos (no error)
   
   Código:
   ```
   function withTimeout(promise, ms, apiName) {
     return Promise.race([
       promise,
       new Promise((_, reject) => 
         setTimeout(() => reject(...), ms)
       )
     ]).catch(error => {
       console.warn(`⏱️ ${apiName} tardó mucho`);
       return [];
     });
   }
   ```

2. PROMISE.ALLSETTLED() - MÁS INTELIGENTE
   ──────────────────────────────────────
   
   Antes usaba: Promise.all()
   ❌ Si una falla, TODO falla
   
   Ahora usa: Promise.allSettled()
   ✅ Cada una es independiente
   ✅ Si una falla, las otras continúan
   
   Código:
   ```
   const results = await Promise.allSettled(searchPromises);
   const allResults = results
     .filter(r => r.status === 'fulfilled' && r.value)
     .map(r => r.value)
     .flat();
   ```

3. TIMEOUTS EN FETCH
   ────────────────
   
   Agregado AbortController a cada fetch:
   ```
   const controller = new AbortController();
   const timeoutId = setTimeout(() => controller.abort(), 4000);
   
   const response = await fetch(url, { signal: controller.signal });
   clearTimeout(timeoutId);
   ```
   
   Ahora:
   • NASA espera máx 5 segundos (muy usada, le damos más tiempo)
   • SpaceX espera máx 4 segundos
   • OpenNotify espera máx 3 segundos (usualmente rápida)
   • RealTime espera máx 3 segundos

🐛 SI ALGO FALLA - SOLUCIONES
════════════════════════════════════════════════════════════════════════════

Problema: Aún espera demasiado
Solución: Reduce los timeouts en la función withTimeout()
  • NASA: 3000 (en lugar de 5000)
  • SpaceX: 2000 (en lugar de 4000)
  • Etc.

Problema: No ve resultados
Solución: Verifica en Console (F12) si hay errores
  • Busca mensajes ⏱️
  • Significa que esa API tardó

Problema: Todavía lento
Solución: Reinicia el servidor
  • Ctrl + C en la ventana cmd
  • python -m http.server 8000
  • Actualiza el navegador (F5)
