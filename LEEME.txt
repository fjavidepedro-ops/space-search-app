❓ PROBLEMAS COMUNES
═════════════════════

"No funciona la app"
→ Verifica que Python esté corriendo en terminal
→ Verifica que escribiste la carpeta correctamente
→ Intenta reiniciar terminal

"No veo resultados"
→ Espera 3-5 segundos (carga datos de internet)
→ Intenta otra búsqueda
→ Prueba con "Posición actual ISS"

"El servidor dice 'puerto en uso'"
→ Cambia 8000 por otro número: python -m http.server 8001

"No tengo Python"
→ Descárgalo de: https://www.python.org/downloads/
